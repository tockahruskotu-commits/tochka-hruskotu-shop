YouTube Data API Services

Опублікувати відео в YouTube

Завантаження виконується через офіційний YouTube Data API v3 після авторизації Google OAuth 2.0.

API підключено. Тестове завантаження відео успішно виконане.

Завантаження відео

Після натискання кнопки відкриється захищена сторінка YouTube Backend «Точки Хрускоту».

На ній ви зможете самостійно обрати відеофайл та параметри завантаження.

1
Оберіть відео MP4, MOV або WebM.
2
Заповніть дані Назва, опис і теги.
3
Контент для дітей Оберіть правильний параметр.
4
Завантажте YouTube поверне video ID.
Під час поточного тестового етапу відео, завантажені через цей API-проєкт, використовуються у режимі Private.

Безпека та контроль користувача

Пароль Google або YouTube не передається «Точці Хрускоту». Авторизація здійснюється Google. Access token і refresh token зберігаються лише на сервері. Відео передається до YouTube тільки після вашої явної дії.
