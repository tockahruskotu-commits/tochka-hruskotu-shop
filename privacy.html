Політика конфіденційності

Останнє оновлення: 9 вересня 2026 року

Ця Політика конфіденційності описує порядок обробки інформації під час використання вебсайту, онлайн-сервісів та інтеграцій бренду «Точка Хрускоту».

Політика, зокрема, поширюється на функції авторизації та роботи з TikTok, Google і YouTube, включаючи підключення облікового запису та передачу вибраного користувачем контенту.

Ми не запитуємо та не зберігаємо паролі від TikTok, Google або YouTube. Авторизація здійснюється через офіційні OAuth та API механізми відповідних платформ.

1. Які дані можуть оброблятися

Ми отримуємо лише інформацію та дозволи, які користувач добровільно надає під час авторизації через відповідну платформу.

Під час підключення TikTok

Залежно від наданих користувачем дозволів це може включати:

  • ідентифікатор облікового запису TikTok;
  • відображуване ім’я;
  • аватар або базову інформацію профілю;
  • OAuth access token та refresh token;
  • інформацію про статус завантаження або публікації контенту;
  • ідентифікатор створеного завдання публікації.

Під час підключення Google / YouTube

«Точка Хрускоту» використовує YouTube API Services.

У поточній інтеграції використовується дозвіл youtube.upload, необхідний для завантаження відео до YouTube від імені користувача після його авторизації.

Ми можемо обробляти:

  • OAuth access token;
  • OAuth refresh token;
  • інформацію про наданий користувачем OAuth-дозвіл;
  • відеофайл, який користувач самостійно вибрав для завантаження;
  • назву відео;
  • опис;
  • теги;
  • інформацію про те, чи призначений контент спеціально для дітей;
  • налаштування приватності публікації;
  • ідентифікатор відео, повернений YouTube після успішного завантаження;
  • технічну інформацію про результат API-запиту.

Ми не збираємо пароль Google-акаунта або YouTube-каналу.

2. Для чого використовуються дані

Дані використовуються виключно для роботи функцій, які користувач свідомо запускає.

Це може включати:

  • авторизацію користувача;
  • підключення TikTok або Google / YouTube;
  • підтримання авторизованої сесії;
  • оновлення access token за допомогою refresh token;
  • передачу вибраного користувачем відео;
  • створення публікації або завантаження відео після явної дії користувача;
  • перевірку результату завантаження або публікації;
  • технічну діагностику роботи інтеграції.

Дані не використовуються для прихованих або вторинних цілей, які не пов’язані з функціями, погодженими користувачем.

3. Публікація та завантаження контенту

Контент не передається до TikTok або YouTube без відповідної авторизації користувача та його дії, спрямованої на завантаження або публікацію.

Перед передачею контенту користувач має можливість перевірити вибраний файл і доступні налаштування.

Користувач самостійно відповідає за контент, який завантажує, та за дотримання авторських прав, прав на приватність, правил відповідної платформи й чинного законодавства.

4. Інтеграція з TikTok

TikTok

Інтеграція здійснюється через офіційні інструменти TikTok for Developers, включаючи Login Kit та Content Posting API.

Використання TikTok також регулюється власними умовами, правилами та політиками TikTok.

«Точка Хрускоту» не є частиною TikTok, не представляє TikTok і не заявляє про партнерство або схвалення з боку TikTok.

5. Інтеграція з YouTube та Google

YouTube API Services

«Точка Хрускоту» використовує YouTube API Services для функцій, пов’язаних із завантаженням відео до YouTube після авторизації користувача.

Підключення здійснюється за допомогою офіційного Google OAuth 2.0.

Використовуючи функції YouTube інтеграції, користувач також погоджується дотримуватися Умов використання YouTube .

Інформація про те, як Google обробляє дані, наведена у Політиці конфіденційності Google .

Використання YouTube API здійснюється відповідно до правил і політик YouTube API Services.

«Точка Хрускоту» не є частиною Google або YouTube, не представляє їх та не заявляє про партнерство, спонсорство чи схвалення з їхнього боку.

6. Передача даних третім сторонам

Ми не продаємо персональні дані користувачів.

Дані можуть передаватися лише в обсязі, технічно необхідному для виконання функції, яку обрав користувач.

До таких сторонніх сервісів можуть належати:

  • TikTok;
  • Google;
  • YouTube;
  • технічні сервіси, що використовуються для роботи вебсайту та серверної частини.

Авторизовані YouTube API Data не передаються стороннім особам для незалежного використання, реклами або перепродажу.

7. Зберігання та захист даних

Дані зберігаються лише настільки, наскільки це необхідно для роботи відповідної інтеграції та виконання дозволених користувачем дій.

Client Secret, access token та refresh token зберігаються у серверному середовищі та не публікуються у відкритому коді вебсторінок.

Ми застосовуємо технічні заходи для обмеження несанкціонованого доступу, зміни або розголошення інформації.

Авторизаційні токени YouTube можуть зберігатися протягом часу, необхідного для роботи дозволеної користувачем інтеграції.

Інші дані YouTube API, якщо вони зберігаються, видаляються або оновлюються відповідно до вимог YouTube API Services Developer Policies.

8. Технічні дані, локальне сховище та журнали

Вебсайт може використовувати технічно необхідне локальне або сесійне сховище браузера, журнали виконання та інші технічні механізми, необхідні для:

  • підтримання сесії;
  • безпечної OAuth-авторизації;
  • запобігання повторному використанню OAuth state;
  • діагностики технічних помилок;
  • коректної роботи сайту.

Ми не використовуємо YouTube API Data для створення прихованих рекламних профілів користувачів.

9. Відкликання доступу

YouTube / Google

Користувач може припинити доступ «Точки Хрускоту» до свого Google / YouTube облікового запису.

Це можна зробити:

  • через функцію «Відключити YouTube» у нашому сервісі, якщо вона доступна;
  • через сторінку налаштувань безпеки Google: Google Security Settings — дозволи сторонніх застосунків .

При використанні нашої функції відключення OAuth token відкликається програмно, а локальна серверна сесія видаляється.

TikTok

Користувач також може відкликати доступ «Точки Хрускоту» до свого TikTok-акаунта через функцію відключення сервісу або налаштування свого TikTok-акаунта.

Користувач має право звернутися із запитом на видалення даних, які зберігаються «Точкою Хрускоту» у зв’язку з роботою інтеграції.
