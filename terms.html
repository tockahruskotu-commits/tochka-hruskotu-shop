Умови використання

Останнє оновлення: 9 вересня 2026 року

Ці Умови використання регулюють використання вебсайту, онлайн-сервісів та цифрових функцій бренду «Точка Хрускоту».

Умови також поширюються на інтеграції з TikTok, Google та YouTube, включаючи авторизацію облікових записів, завантаження відео та публікацію контенту.

Використовуючи функції інтеграції з TikTok, Google або YouTube, користувач підтверджує, що має право керувати відповідним обліковим записом і передавати вибраний ним контент.

1. Призначення сервісу

«Точка Хрускоту» надає вебінтерфейс та допоміжні цифрові функції для:

  • підготовки контенту;
  • вибору відеофайлів;
  • підключення авторизованих соціальних облікових записів;
  • налаштування параметрів публікації;
  • завантаження або публікації контенту до підтримуваних платформ;
  • отримання технічного результату виконаної користувачем операції.

Функціональність сервісу може змінюватися залежно від доступності API, правил та технічних вимог сторонніх платформ.

2. Авторизація облікових записів

Підключення сторонніх облікових записів здійснюється через офіційні механізми авторизації відповідних платформ.

Для Google / YouTube використовується Google OAuth 2.0.

Для TikTok використовується офіційна система TikTok Login Kit.

«Точка Хрускоту» не отримує пароль користувача від TikTok, Google або YouTube.

Користувач самостійно:

  • обирає обліковий запис;
  • переглядає запитувані дозволи;
  • погоджується або відмовляється від них;
  • може надалі відкликати доступ.

3. Інтеграція з TikTok

TikTok

Інтеграція з TikTok здійснюється через офіційні інструменти TikTok for Developers, у тому числі Login Kit та Content Posting API.

Доступні функції можуть включати авторизацію, вибір параметрів публікації, передачу відео та отримання статусу публікації.

Використання TikTok регулюється також власними правилами, умовами та політиками TikTok.

Користувач зобов’язаний самостійно забезпечувати відповідність свого контенту правилам TikTok.

4. Інтеграція з Google та YouTube

YouTube API Services

«Точка Хрускоту» використовує YouTube API Services для функцій, пов’язаних із завантаженням відео до YouTube.

Для авторизації використовується Google OAuth 2.0.

Поточна інтеграція використовує дозвіл youtube.upload для передачі відео до YouTube від імені авторизованого користувача.

Використовуючи функції YouTube у сервісі «Точка Хрускоту», користувач погоджується також дотримуватися Умов використання YouTube .

Використання функцій YouTube API здійснюється відповідно до правил та політик YouTube API Services.

Інформація про обробку даних Google наведена у Політиці конфіденційності Google .

5. Завантаження та публікація відео

Перед передачею відео користувач самостійно обирає файл та заповнює доступні параметри.

Для YouTube вони можуть включати:

  • відеофайл;
  • назву відео;
  • опис;
  • теги;
  • параметр щодо контенту, призначеного для дітей;
  • доступний режим видимості.

Для TikTok користувач також може мати можливість обирати параметри видимості, взаємодії та інші налаштування, які повертає або дозволяє TikTok.

Передача контенту не повинна починатися без відповідної дії користувача.

Після запуску операції стороння платформа самостійно обробляє переданий файл відповідно до власних правил.

6. Контент для дітей

«Точка Хрускоту» не позиціонує свій API-клієнт як сервіс, спеціально спрямований на дітей.

Під час завантаження відео до YouTube користувач повинен правильно зазначити, чи є конкретний контент спеціально призначеним для дітей.

Користувач несе відповідальність за правильність такого визначення.

7. Вимоги до контенту

Користувач може передавати через сервіс лише контент, щодо якого він має необхідні права.

Забороняється використовувати сервіс для матеріалів, які:

  • порушують законодавство;
  • порушують авторські або суміжні права;
  • незаконно використовують торговельні марки;
  • порушують право на приватність;
  • порушують правила TikTok, Google або YouTube;
  • містять матеріали, які користувач не має права публікувати.

8. Права на контент

«Точка Хрускоту» не набуває права власності на відео, фото, тексти або інші матеріали користувача лише через їх передачу через сервіс.

Користувач надає лише той обсяг технічного дозволу, який необхідний для передачі контенту до обраної ним сторонньої платформи.

9. Конфіденційність

Порядок обробки OAuth token, API Data, технічної інформації та інших даних описаний у Політиці конфіденційності «Точки Хрускоту» .

Використовуючи відповідні інтеграції, користувач підтверджує, що ознайомився з Політикою конфіденційності.

10. Робота сторонніх сервісів

Частина функціональності «Точки Хрускоту» залежить від сторонніх платформ.

До них належать, зокрема:

  • TikTok;
  • Google;
  • YouTube;
  • Google Apps Script;
  • інші технічні сервіси інфраструктури.

«Точка Хрускоту» не може гарантувати безперервну доступність функцій, які залежать від API, технічних систем, квот, обмежень або правил сторонніх платформ.

11. Безпека

Користувач повинен самостійно забезпечувати безпеку своїх Google, YouTube та TikTok-акаунтів.

Користувач не повинен передавати третім особам:

  • паролі;
  • секретні ключі;
  • access token;
  • refresh token;
  • інші конфіденційні дані доступу.

12. Припинення використання та відкликання доступу

Користувач може припинити використання інтеграції у будь-який момент.

Google / YouTube

Доступ можна відкликати через функцію «Відключити YouTube», якщо вона доступна в інтерфейсі, або через налаштування дозволів Google .

TikTok

Доступ до TikTok можна припинити через функцію відключення сервісу або через налаштування облікового запису TikTok.

13. Доступність сервісу

Ми прагнемо підтримувати працездатність сервісу, однак не гарантуємо, що всі функції будуть доступні безперервно.

Тимчасова недоступність може бути пов’язана з:

  • технічними роботами;
  • змінами API;
  • обмеженнями квоти;
  • змінами правил сторонніх платформ;
  • перебоями зовнішніх сервісів.

14. Відповідальність користувача

Користувач несе відповідальність за:

  • вибір контенту;
  • правильність назви та опису;
  • налаштування публікації;
  • наявність прав на матеріали;
  • дотримання правил платформи;
  • правильне визначення контенту для дітей;
  • законність здійсненої публікації.

15. Зміни сервісу та Умов

«Точка Хрускоту» може змінювати функціональність сервісу у зв’язку з його розвитком або змінами сторонніх API.

Ці Умови також можуть оновлюватися.

Актуальна редакція завжди публікується на цій сторінці із зазначенням дати останнього оновлення.

16. Відсутність афілійованості

TikTok, Google та YouTube є торговельними марками відповідних правовласників.

«Точка Хрускоту» не є частиною TikTok, Google або YouTube та не заявляє про партнерство, спонсорство, представництво або схвалення з їхнього боку, якщо інше прямо не підтверджено відповідною платформою.

17. Застосовне законодавство

Використання сервісу здійснюється відповідно до чинного законодавства України, а також обов’язкових правил і умов відповідних сторонніх платформ.
