TikTok

Production review

Інтеграція TikTok уже пройшла успішне Sandbox-тестування. Production-застосунок зараз перебуває на перевірці TikTok.

  • Login Kit
  • Content Posting API
  • Direct Post
  • Тестове завантаження підтверджене статусом PUBLISH_COMPLETE

YouTube

API підключено

Google OAuth та YouTube Data API v3 успішно підключені. Тестове відео вже було реально завантажене через API.

  • Google OAuth 2.0
  • YouTube Data API v3
  • youtube.upload
  • Resumable upload працює

Підключення

  • Reels
  • окремий текст для Instagram
  • автоматизація публікацій

Facebook

Підключення

Facebook також буде працювати через цей центр після завершення Meta API інтеграції.

  • Facebook Page
  • відео та Reels
  • окремий текст для Facebook
Скоро буде доступно Наш Facebook
Як це працюватиме далі: зараз кожна платформа має власну сторінку публікації. Після підключення всіх API ми зможемо зробити спільний режим: вибрати одне відео, відмітити TikTok, YouTube, Instagram та Facebook і підготувати окремий текст для кожної платформи.
