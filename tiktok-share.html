1. Підключи свій TikTok

Авторизація проходить через офіційний TikTok Login Kit. Client Secret, access token і refresh token залишаються тільки на сервері.

TikTok ще не підключений.

2. Додай відео

Для першого Direct Post-тесту використовуємо лише відео. Фото / карусель підключимо окремо після успішного тесту.

Після входу TikTok поверне максимальну тривалість відео для цього профілю.

3. Налаштування публікації

Варіанти отримані з TikTok Creator Info. Видимість не вибирається автоматично. Для нашого Sandbox-тесту потрібно обрати «Тільки я».
